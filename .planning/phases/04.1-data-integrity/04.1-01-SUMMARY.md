# Phase 4.1 Plan 01: Silent Failure Bug Fixes Summary

Eliminated two pure-function bugs: FRED vintage silent fallback enabling look-ahead bias, and maxDrawdown emitting -1.0 as a false 100% loss metric for empty series.

## Tasks Completed

| Task | Name | Commit | Files |
|------|------|--------|-------|
| 1 | Throw on FRED vintage failure — remove silent fallback | 6155c9e | lib/macro-engine/providers/alfred.ts |
| 2 | Guard maxDrawdown against empty/all-zero returns + update types | 9076aae | lib/macro-engine/backtest/metrics.ts, types.ts, index.ts |

## What Was Built

**Task 1 — FRED vintage throw-on-error:**
Removed two `return fetchFredCurrentObservations(...)` call sites inside `fetchFredAllVintages`. Both the HTTP error path (400/5xx) and the empty-rows edge case now throw explicit errors instead of silently falling back to current observations. The `fetchFredCurrentObservations` private function definition is preserved unchanged. This eliminates a look-ahead bias source — current observations include retroactive revisions that were not available at the original observation date.

**Task 2 — maxDrawdown null guard:**
Added two early-return guards before the drawdown accumulation loop: empty `periodReturns` array returns `null` with a console warning; all-zero `periodReturns` returns `null` (no meaningful drawdown to compute). Changed the return type from `number` to `number | null`. Updated `MetricsResult.maxDrawdown` in types.ts to `number | null`. Updated two console.log lines in index.ts to use optional chaining (`?.toFixed(3) ?? 'null'`). Added `?? 0` in `toMetricRow` for the Prisma DB write only (schema field is non-nullable `Float`).
