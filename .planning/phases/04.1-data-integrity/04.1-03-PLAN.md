  <action>
    Create the file at `scripts/macro-engine/report-data-quality.ts`. Follow the same print helper style as `scripts/macro-engine/report-data-foundation.ts` (padEnd, padStart, separator, row functions).

    The script must do two things:

    **Section A — FactorFeatureMatrix null coverage by year:**

    Run a single SQL query that returns, for each (year, factor), the count of non-null values and total rows. Build the result using `prisma.$queryRaw`. Use `EXTRACT(YEAR FROM "feature_date")` for year grouping. The six factors to check: zGrowth, zInflation, zMonetary, zCredit, zCarry, zEarnings.

    Query template (use Prisma.sql tagged template, not string interpolation):
    ```sql
    SELECT
      EXTRACT(YEAR FROM feature_date)::int AS year,
      COUNT(*) AS total,
      COUNT(z_growth)    AS z_growth_count,
      COUNT(z_inflation) AS z_inflation_count,
      COUNT(z_monetary)  AS z_monetary_count,
      COUNT(z_credit)    AS z_credit_count,
      COUNT(z_carry)     AS z_carry_count,
      COUNT(z_earnings)  AS z_earnings_count
    FROM factor_feature_matrix
    GROUP BY 1
    ORDER BY 1
    ```

    Print a table with columns: year | total | zGrowth% | zInflation% | zMonetary% | zCredit% | zCarry% | zEarnings% | status

    For each row, compute null % per factor as `((total - factorCount) / total * 100)`. If ANY factor has null% > 20, print `WARNING` in the status column. Otherwise print `ok`.

    Print a summary line at the end: "X of Y years have at least one factor with >20% null data."

    **Section B — OhlcvDaily ticker coverage:**

    Query the distinct tickers present in OhlcvDaily:
    ```typescript
    const present = await prisma.ohlcvDaily.findMany({
      distinct: ['ticker'],
      select: { ticker: true },
    });
    ```

    Get the universe ticker list via `getUniverse()`. Compare: find tickers in universe that have zero rows in OhlcvDaily.

    Print a table: ticker | status (present / MISSING)

    Print a summary line: "X of Y universe tickers have OHLCV data."

    **Exit behavior:** Always `process.exit(0)` at end — this is a display script, not a gate. Print "report:data-quality complete" as the last line.
