Create lib/macro-engine/query.ts (server-only, no "use client"). Export the following read-only functions:

```typescript
// Returns OHLCV rows for a ticker in [startDate, endDate]
export async function getOhlcv(
  ticker: string, startDate: Date, endDate: Date
): Promise<OhlcvDailyRow[]>

// Returns the FRED value as it was known on asOfDate (point-in-time vintage lookup)
// Logic: WHERE series_id = seriesId AND observation_date <= asOfDate
//        AND realtime_start <= asOfDate AND realtime_end >= asOfDate
//        ORDER BY realtime_start DESC LIMIT 1
export async function getFredAsOf(
  seriesId: string, observationDate: Date, asOfDate: Date
): Promise<MacroSeriesVintageRow | null>

// Returns all earnings revisions for a symbol up to asOfDate
export async function getRevisions(
  symbol: string, asOfDate: Date
): Promise<EarningsRevisionRow[]>

// Returns OECD CLI series for a country in [startDate, endDate]
export async function getOecdCli(
  country: string, startDate: Date, endDate: Date
): Promise<OecdCliRow[]>

// Returns coverage stats per ticker: { ticker, earliest, latest, rowCount }
export async function getOhlcvCoverage(): Promise<CoverageRow[]>

// Returns count of FRED rows missing realtimeStart (should be 0)
export async function getFredVintageIntegrity(): Promise<{ seriesId: string; missingVintage: number }[]>
```

All functions use `prisma.$queryRaw` tagged template literals — no string interpolation (SQL injection risk).

<task type="auto">
  <name>Task 2: Build hard-failing Phase 1 verification harness</name>
  <files>scripts/macro-engine/verify-data-foundation.ts, scripts/macro-engine/report-data-foundation.ts, package.json</files>
  <action>
Create scripts/macro-engine/verify-data-foundation.ts:

Checks (each is a PASS/FAIL assertion that drives exit code):
1. OHLCV 20+ year coverage: for each ticker in universe, earliest row date <= inceptionDate + 30 days AND rowCount >= 4000
2. Inception-date compliance: no rows exist where date < inceptionDate (query: SELECT ticker, COUNT(*) FROM ohlcv_daily WHERE date < $inceptionDate)
3. ALFRED vintage integrity: getFredVintageIntegrity() returns all zeros (no rows missing realtimeStart)
4. FRED point-in-time spot check: getFredAsOf('GDP', '2010-01-01', '2010-03-01') returns a non-null value AND the returned value matches the FRED March 2010 advance GDP estimate (stored vintage, not revised) — log the value for manual confirmation
5. Earnings revision presence: for each equity in universe, at least 1 EarningsRevision row exists
6. OECD coverage: for each country in universe config, at least 12 OecdLeadingIndicator rows exist

Print each check as: [PASS] or [FAIL] {description}
On any FAIL → process.exit(1)
On all PASS → process.exit(0)

Create scripts/macro-engine/report-data-foundation.ts:
- Runs all the same queries but prints a human-readable coverage table instead of pass/fail
- Format: ASCII table with ticker, earliest, latest, row_count, status columns
- Never exits non-zero — this is a display-only report

Add to package.json scripts:
- `"verify:data": "npx tsx scripts/macro-engine/verify-data-foundation.ts"`
- `"report:data": "npx tsx scripts/macro-engine/report-data-foundation.ts"`
  </action>

  </verify>
  <done>npm run verify:data exits non-zero when any check fails. All 6 checks run and print [PASS]/[FAIL] lines. npm run report:data prints a coverage table and always exits 0.</done>
