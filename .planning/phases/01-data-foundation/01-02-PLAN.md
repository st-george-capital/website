Create lib/macro-engine/providers/alpha-vantage.ts. Export:

```typescript
export async function fetchFullOhlcv(ticker: string): Promise<OhlcvDailyRow[]>
export async function fetchOhlcvSince(ticker: string, since: Date): Promise<OhlcvDailyRow[]>
```

Implementation requirements for fetchFullOhlcv:
- Endpoint function: `TIME_SERIES_DAILY_ADJUSTED` — NOT `TIME_SERIES_DAILY` (unadjusted produces split-distorted prices, corrupts momentum factors)
- outputsize: `full` — returns 20+ years of history; this is a premium-only param
- Response key: `'Time Series (Daily Adjusted)'`
- Map fields: open=`1. open`, high=`2. high`, low=`3. low`, close=`4. close`, adjClose=`5. adjusted close`, volume=`6. volume`, dividendAmt=`7. dividend amount`, splitCoeff=`8. split coefficient`
- Return typed rows: `{ ticker, date: Date, open, high, low, close, adjClose, volume: bigint, dividendAmt, splitCoeff }`

For sequential staggered fetching across a universe, export:
```typescript
export async function fetchUniverseOhlcv(
  tickers: string[],
  staggerMs = 800   // 75 req/min premium = ~800ms between calls
): Promise<{ ticker: string; rows: OhlcvDailyRow[]; error?: string }[]>
```
This must use a for...of loop with await — never Promise.all or Promise.allSettled for AV.

Reuse the private fetchAlphaVantage() pattern from lib/alpha-vantage.ts (examine that file to understand the existing rate-limit detection for 'Note' and 'Information' response keys). Do NOT modify lib/alpha-vantage.ts — create the macro-engine adapter as a separate module.

Add OhlcvDailyRow type to lib/macro-engine/types.ts.
  </action>
