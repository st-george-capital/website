<task type="auto">
  <name>Task 1: Build source-specific persistence pipelines</name>
  <files>lib/macro-engine/ingest/prices.ts, lib/macro-engine/ingest/macro-series.ts, lib/macro-engine/ingest/revisions.ts</files>
  <action>
Create three ingest modules. Each must be independently retryable and must upsert idempotently.

lib/macro-engine/ingest/prices.ts:
- Export `ingestPrices(universe: UniverseEntry[], opts: { dryRun: boolean }): Promise<IngestResult>`
- Calls fetchUniverseOhlcv() from providers/alpha-vantage.ts (sequential stagger built into provider)
- Before writing, filter rows where `date < new Date(entry.inceptionDate)` — DO NOT write pre-inception rows
- Upsert via prisma.$executeRaw using INSERT ... ON CONFLICT (ticker, date) DO UPDATE
- Return { source: 'alpha-vantage', rowsUpserted, errors[] }

lib/macro-engine/ingest/macro-series.ts:
- Export `ingestMacroSeries(seriesIds: string[], opts: { dryRun: boolean }): Promise<IngestResult>`
- Calls fetchFredAllVintages() from providers/alfred.ts for each series ID
- FRED series to ingest (hardcoded in this module, exposed as a constant): GDP, UNRATE, CPIAUCSL, FEDFUNDS, T10Y2Y, INDPRO (6 series for Phase 2 factor matrix)
- Upsert via INSERT ... ON CONFLICT (series_id, observation_date, realtime_start) DO UPDATE
- Return { source: 'fred', rowsUpserted, errors[] }

lib/macro-engine/ingest/revisions.ts:
- Export `ingestRevisions(tickers: string[], opts: { dryRun: boolean }): Promise<IngestResult>`
- Calls fetchAnalystEstimates() from providers/fmp.ts for equities in universe
- Also calls fetchOecdCliForCountry() from providers/oecd.ts for all countries in universe
- Upserts both EarningsRevision and OecdLeadingIndicator rows
- Return { source: 'fmp+oecd', rowsUpserted, errors[] }
  </action>
  <verify>
    <automated>npx tsx -e "import { ingestPrices } from './lib/macro-engine/ingest/prices'; import { getUniverse } from './lib/macro-engine/universe'; const u = getUniverse().slice(0,1); ingestPrices(u, { dryRun: true }).then(r => console.log('Dry run prices:', r)).catch(e => { console.error(e.message); process.exit(1) })"</automated>
  </verify>
  <done>Each source module runs dry-run successfully against a 1-ticker subset and reports intended row counts without schema errors.</done>
</task>

Create lib/macro-engine/ingest/logging.ts:
- Export `logIngestRun(prisma, result: IngestResult): Promise<void>`
- Writes one IngestLog row per result with source, rowsUpserted, status ('success'|'error'|'partial'), errorMsg, runAt

Create lib/macro-engine/ingest/index.ts as the orchestrator:
1. Call checkTimescaleDb() — exit non-zero if fails
2. Validate all required env vars (ALPHA_VANTAGE_API_KEY, FRED_API_KEY, FMP_API_KEY) — throw descriptive error if any missing
3. Load universe from getUniverse()
4. Run stages in order: prices → macro-series → revisions
5. Log each stage result via logIngestRun()
6. Print summary table: source, rows, status
7. Exit non-zero if any stage has status 'error'

Create scripts/macro-engine/run-ingest.ts:
- Parses CLI flags: --dry-run, --source=prices|macro|revisions (run one stage only)
- Calls orchestrator with flags
- Exits with process.exit(code) from orchestrator result

Add to package.json scripts:
- `"ingest": "npx tsx scripts/macro-engine/run-ingest.ts"`
- `"ingest:dry": "npx tsx scripts/macro-engine/run-ingest.ts --dry-run"`
