**lib/macro-engine/signals/analyst.ts**

Export `AnalystConsensus` interface and `fetchAnalystConsensus(tickers: string[]): Promise<Map<string, AnalystConsensus | null>>`.

Implementation:
1. Check FMP_API_KEY env var — throw with clear message if missing (same pattern as providers/fmp.ts).
2. For each ticker (sequentially — NOT parallel):
   a. Try `/v4/grades-consensus/{symbol}` first. Parse `{ strongBuy, buy, hold, sell, strongSell }`.
   b. If 403/tier error: log warning, set result to null for this ticker.
   c. If 200 but empty object/null: fall back to `/v3/analyst-stock-recommendations/{symbol}` — take the first/latest row, map `analystRatingsStrongBuy`→`strongBuy`, `analystRatingsBuy`→`buy`, etc.
   d. If both fail: set result to null (do NOT throw — cron must continue).
   e. After each ticker: `await new Promise(r => setTimeout(r, 800))` — rate-limit safety.
3. Return a Map keyed by ticker (value is AnalystConsensus | null).

All fetch errors are caught and logged — never thrown. The overlay is enrichment, not a hard dependency.

**lib/macro-engine/signals/index.ts — extend runDailySignals():**

After writing StockScreenResult rows (from Plan 03), fetch analyst consensus for the screened equities and update the analystConsensus field:

```typescript
const screenedTickers = screenedEquities.map(e => e.ticker);
if (screenedTickers.length > 0) {
  const consensusMap = await fetchAnalystConsensus(screenedTickers);
  for (const ticker of screenedTickers) {
    const consensus = consensusMap.get(ticker) ?? null;
    if (consensus !== undefined) {
      await prisma.stockScreenResult.update({
        where: { runDate_ticker: { runDate: asOfDate, ticker } },
        data: { analystConsensus: consensus },
      });
    }
  }
}
```
