RS Rating proxy formula (from research — confirmed from multiple community sources):
```typescript
// Published weighted-ROC formula — NOT the official IBD RS rating
// Must be labeled "RS Proxy (universe-relative)" in all output
RSScore = 0.4 * ROC(63d) + 0.2 * ROC(126d) + 0.2 * ROC(189d) + 0.2 * ROC(252d)
RSRating = percentile_rank(RSScore, universe) * 99  // 1-99 scale, ranked ONLY within proxy list
```

DMA position via window function (from research):
```sql
SELECT
  ticker,
  "adjClose",
  AVG("adjClose") OVER (
    PARTITION BY ticker
    ORDER BY date
    ROWS BETWEEN 49 PRECEDING AND CURRENT ROW
  ) AS ma50
FROM ohlcv_daily
WHERE ticker = ANY($tickers)
  AND date >= (CURRENT_DATE - INTERVAL '300 days')
ORDER BY ticker, date DESC
```

ScreenedEquity interface:
```typescript
export interface ScreenedEquity {
  ticker: string;
  sectorEtf: string;
  rsRating: number | null;         // 1-99 proxy (universe-relative within proxy list ONLY)
  epsRankProxy: number | null;     // 0-99 percentile EPS growth vs proxy peers
  smrProxy: string | null;        // "A"-"E" from revenue/margin trend (FMP not called in Plan 03 — null for now)
  dma50Position: number | null;   // (close/MA50 - 1)
  dma100Position: number | null;
  dma200Position: number | null;
  institutionalSponsorshipTrend: number | null;  // 30d avg vol delta YoY proxy
  earningsRevisionMomentum: number | null;        // zEarnings from FactorFeatureMatrix
  compositeScore: number;
}
```

**screenEquities() implementation:**

1. For each overweight sector, look up its proxy tickers from EQUITY_PROXY_MAP. Skip sectors not in the map (return empty for them).
2. If no overweight sectors have proxy tickers, return [].
3. Fetch the most recent 300 days of OHLCV data for all proxy tickers in a single query:
   ```sql
   SELECT ticker, date, "adjClose", volume
   FROM ohlcv_daily
   WHERE ticker = ANY($tickers)
     AND date >= (CURRENT_DATE - INTERVAL '300 days')
   ORDER BY ticker, date ASC
   ```
4. **RS Proxy:**
   - For each ticker: compute ROC(63), ROC(126), ROC(189), ROC(252) days.
   - RSScore = 0.4*ROC63 + 0.2*ROC126 + 0.2*ROC189 + 0.2*ROC252
   - Rank all tickers by RSScore, assign percentile × 99.
   - Label this field explicitly as "RS Proxy (universe-relative)" in schema comments — not IBD RS rating.
   - Return null if any ROC period is missing.

5. **DMA positions:**
   - MA50 = average of last 50 adjClose values for ticker.
   - MA100 = average of last 100 adjClose values.
   - MA200 = average of last 200 adjClose values.
   - dmaXXPosition = (latestClose / MAxx) - 1.
   - Return null if insufficient price history.

6. **Institutional sponsorship trend proxy:**
   - Compare 30-day average volume (most recent 30 days) vs. 30-day average volume from 1 year ago.
   - institutionalSponsorshipTrend = (vol30d_recent / vol30d_year_ago) - 1.
   - Return null if insufficient history.

7. **Earnings revision momentum:**
   - Query FactorFeatureMatrix for the most recent row for this ticker: `SELECT zEarnings FROM factor_feature_matrix WHERE ticker = $ticker ORDER BY featureDate DESC LIMIT 1`.
   - Return null if no row exists.

8. **EPS rank proxy:**
   - Query EarningsRevision for 3-year EPS growth: compute (latest estimatedEpsAvg - estimatedEpsAvg 3 years ago) / |estimatedEpsAvg 3 years ago|.
   - Rank among all proxy tickers by this growth rate, assign percentile × 99.
   - Return null if data is insufficient.

9. **SMR proxy:**
   - Set to null in Plan 03. The analyst.ts plan (Plan 04) will optionally populate this from FMP income statement data.

10. **Composite score:**
    ```
    compositeScore = weighted average of available non-null fields:
      rsRating (weight 0.25, normalized to 0-1 as rsRating/99)
      epsRankProxy (weight 0.20, normalized as epsRankProxy/99)
      dma50Position clamped to [-0.3, 0.3] then normalized (weight 0.15)
      institutionalSponsorshipTrend clamped to [-0.5, 0.5] then normalized (weight 0.15)
      earningsRevisionMomentum clamped to [-3, 3] then normalized (weight 0.25)
    Normalize weights to sum to 1.0 excluding null fields.
    ```
