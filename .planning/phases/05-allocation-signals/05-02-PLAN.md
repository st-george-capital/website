Create `lib/macro-engine/signals/probabilities.ts` with a single exported function:

```typescript
export async function computeOutperformanceProbabilities(
  entries: Array<{ ticker: string; convictionScore: number; regimeLabel: string }>,
  asOfDate: Date,
): Promise<Map<string, { prob6m: number; prob12m: number }>>
```

**Algorithm:**

1. Restrict calibration data to `featureDate < HOLDOUT_START` (import from backtest/types.ts). Never use post-HOLDOUT_START data.

2. Query historical FactorFeatureMatrix (pre-HOLDOUT_START) to get (featureDate, ticker) pairs. Use `prismaDirectUrl`.

3. For each historical (featureDate, ticker) pair, compute conviction score by scoring with the latest FactorWeightSet — same logic as scoreUniverse() but applied to historical rows. This builds the calibration distribution.
   - IMPORTANT: To keep the function fast and avoid re-deriving weights, accept the weight vector as a parameter OR fetch it once at the start.

4. Compute forward returns at 126 and 252 days for the same (featureDate, ticker) pairs:
   ```sql
   -- For each (ticker, featureDate), find adjClose at featureDate+126 and featureDate+252
   -- Compare against SPY return over same window
   -- hit_6m = 1 if ticker_6m_return > spy_6m_return, else 0
   ```
   Use raw SQL via `prismaDirectUrl.$queryRaw` to join ohlcv_daily to itself at offset windows. Fetch base and forward prices in a single query using two self-joins.

5. Assign each historical observation a conviction decile bucket (0–9) using Math.floor(convictionScore * 10), capped at 9.

6. Group by (regimeLabel, decileBucket). Compute:
   - `hitRate6m = count(hit_6m=1) / total_obs` per group
   - `hitRate12m = count(hit_12m=1) / total_obs` per group

7. For each input `entry`, look up its `(regimeLabel, decileBucket)` → `{prob6m, prob12m}`. Fall back to global decile bucket (ignoring regime) if the regime-specific bucket has < 5 observations. Fall back to 0.5 for both if no calibration data exists for the bucket.

8. Clamp all output probabilities to [0.05, 0.95] to avoid reporting 0.0 or 1.0 from thin buckets.

9. Return a Map keyed by ticker.

**Performance note:** The historical calibration query may involve thousands of rows. Run it once per call (not per ticker). Total rows = ~15 years × 252 days × 12 tickers ≈ 45,000 rows — acceptable for a single query.

**Do NOT:**
- Re-train any weights in this function
- Use data from featureDate >= HOLDOUT_START
- Call any external API
