**lib/macro-engine/signals/conviction.ts**

Export two functions:
- `normalizeConviction(scores: number[]): number[]` — min-max normalize to [0,1], handles zero-range by returning 0.5 for all
- `attributeFactors(weights: number[], zScores: number[], dims: readonly string[]): Record<string, number>` — returns `{ dimName: w_i * z_i }` for each dimension

**lib/macro-engine/signals/scoring.ts**

Export `ScoredEntry` interface and `scoreUniverse(asOfDate: Date): Promise<ScoredEntry[]>`.

ScoredEntry must have: ticker, score, convictionScore, direction ('overweight'|'underweight'|'neutral'), factorAttribution (Record<string,number>), regimeLabel, etfTicker.

Implementation:
1. Throw `Error('No BacktestRun found. Run npm run backtest:run first.')` if prisma.backtestRun.findFirst() returns null.
2. Look up latest FactorWeightSet: prefer regimeLabel match, fall back to `isFallback: true` row from the same runId. If no weight set at all, throw.
3. Query FactorFeatureMatrix for the MOST RECENT feature date at or before `asOfDate` — use `ORDER BY featureDate DESC LIMIT 1` to find the latest available feature date, then fetch all tickers for that date. Log which feature date is actually used (to detect staleness per Pitfall 1 in research).
4. Use BACKTEST_FEATURE_DIMS from `lib/macro-engine/backtest/types.ts` as the 6-dimension order.
5. Compute direction threshold: convictionScore > 0.6 → overweight, < 0.4 → underweight, else neutral.
6. Set etfTicker = ticker (ETFs are their own entry vehicle).
7. Use `prismaDirectUrl` from `lib/macro-engine/db.ts`.

**lib/macro-engine/signals/index.ts**

Export `runDailySignals(asOfDate?: Date): Promise<{ runDate: string; signalCount: number; regimeLabel: string }>`.

Implementation:
1. Default asOfDate to today (new Date()).
2. Call scoreUniverse(asOfDate).
3. Assign rank by descending score (rank 1 = highest score).
4. Upsert each ScoredEntry into AllocationSignal with `prisma.allocationSignal.upsert({ where: { runDate_ticker }, create: {...}, update: {...} })`. Note: prob6m and prob12m are null at this stage — they will be filled in by Plan 02.
5. Return { runDate, signalCount, regimeLabel }.

**app/api/cron/signals/route.ts**

```typescript
import { type NextRequest } from 'next/server';
export const dynamic = 'force-dynamic';

export async function GET(request: NextRequest) {
  const authHeader = request.headers.get('authorization');
  if (authHeader !== `Bearer ${process.env.CRON_SECRET}`) {
    return new Response('Unauthorized', { status: 401 });
  }
  try {
    const { runDailySignals } = await import('../../../../lib/macro-engine/signals');
    const result = await runDailySignals();
    return Response.json({ ok: true, ...result });
  } catch (err) {
    console.error('signals cron failed:', err);
    return Response.json({ ok: false, error: String(err) }, { status: 500 });
  }
}
```

**scripts/macro-engine/run-signals.ts**

Follow the same pattern as `scripts/macro-engine/run-backtest.ts`:
- `#!/usr/bin/env tsx` shebang + `export {};`
- Prepend DIRECT_URL override if DATABASE_URL is Accelerate.
- `--dry-run` flag: resolve imports, print "signals:run dry-run" + asOfDate + config info, exit without DB operations.
- `--help` flag: print usage.
- Default: call `runDailySignals()`, print result, suggest `npm run verify:signals`.

**scripts/macro-engine/verify-signals.ts**

Single script with flag-based checks (consistent with verify-backtest.ts pattern). Flags:
- `--check-rows`: Assert AllocationSignal rows exist for today (or most recent runDate), count = universe size.
- `--check-fields`: Assert each row has non-null convictionScore, factorAttribution (is JSON object), regimeLabel, etfTicker, rank, direction.
- `--check-probs`: Assert prob6m and prob12m are null or float in [0,1]. (They will be null at this stage — pass if null.)
- `--check-stocks`: Assert StockScreenResult rows exist for at least one ticker (will be empty at this stage — print warning only, do not fail).
- `--check-analyst`: Assert analystConsensus is present or print "not yet populated" (will be null at this stage — print warning only, do not fail).
- Default (no flag): Run --check-rows and --check-fields only.

All checks use `prismaDirectUrl` and exit non-zero only on genuine failures.
