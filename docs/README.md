# Documentation map

Repository documentation is organized by purpose so operational notes do not clutter the application root.

- `admin/` — dashboard workflows for people, permissions, settings, uploads, and published content.
- `setup/` — local setup, deployment, and project orientation.
- `changelog/` — dated implementation notes.
- `archive/` — historical completion and fix summaries kept for reference.
- `debug/` — DCF diagnostic notes.

The dashboard’s **Help & guides** button provides the current, member-facing workflows for adding team members, managing permissions, publishing content, and generating marketing materials.
